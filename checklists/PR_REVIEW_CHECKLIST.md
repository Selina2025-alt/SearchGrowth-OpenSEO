- [ ] relevant ADR read
- [ ] no duplicate OpenSEO capability
- [ ] D1/Postgres parity
- [ ] input validation
- [ ] missing data not silently zero
- [ ] external request timeout/error normalization
- [ ] no cookie/token/secret in logs
- [ ] SafeOutboundUrl where applicable
- [ ] safe HTML rendering
- [ ] prompt injection boundary
- [ ] idempotency for side effects
- [ ] legal state transition/CAS
- [ ] audit for approval/publish/security actions
- [ ] unit tests
- [ ] integration tests
- [ ] original OpenSEO regression
- [ ] docs/contracts updated
